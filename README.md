# Data Profiler Dashboard

A lightweight Streamlit dashboard for quickly profiling CSV and Parquet datasets.

## Why I built this

This project demonstrates practical data engineering skills including data profiling, data quality checks, testing, and dashboard development.

## Features

- Upload CSV files
- Upload Parquet files
- Preview datasets
- Data quality metrics
- Missing value analysis
- Download reports

## Tech Stack

- Python
- Streamlit
- Pandas
- PyArrow
- Pytest
